# 每月收租管理系統

GitHub Pages 是公開入口；收租表單及資料由僅限本人存取的 Google Apps Script Web App 提供。公開儲存庫只包含程式碼與受 Google 登入保護的 Web App 連結，不包含租客資料、試算表 ID、權杖或金鑰。

## 使用
開啟 GitHub Pages 入口後按「登上我的島嶼城市」，使用部署時授權的 Google 帳號登入。預設進入「棲島日常」3D 城市，仍可切換至「收租戰情室」及「收款登錄」。

## 棲島日常：互動城市
- 各物件島依私人設定由 5 至 12 塊相連六角地塊組成，預設 7 塊；中央戰情室有 19 塊，面積最大。島內陸地無水隙、步道互通；鄰近島嶼以短木橋連接，水道保留流動波紋，跨島木橋僅供房東巡視。點島可看應收、實收、待收與逐筆登錄入口。房屋、樹木、生活設施與角色皆為程序生成的 3D 模型。
- 溫暖的玩具微縮模型風格，僅保留中央戰情室與具名物件島；相鄰海岸由短木橋連接。中央戰情室可直接開啟收租總覽。
- 可拖曳旋轉、滾輪或雙指縮放；提供縮放、回全景及標籤切換。日夜按鈕依序切換白晝、黃昏、夜晚、自動日夜；自動模式約三分鐘循環，窗戶與路燈會在夜間亮起。鍵盤可在城市畫布上使用方向鍵、加減號與 Home，亦可用「快速登島」及文字清單操作。
- 找找花園鹿角狐、中央島小船遊戲角的蜜蜂柯基與夜晚屋頂的羽耳兔，點角色或「尋找角色彩蛋」可發現三個小驚喜。彩蛋進度只留在本次頁面。
- 島民有鹿角狐、羽耳兔、雲翼貓、苔甲獺、浣尾熊貓、企鵝海豹、蜜蜂柯基、花鰓小鹿八種混合生物，可取名字、選顏色與居住島嶼，並打招呼或送果實。九位導覽訪客分散在小島散步；常住島民最多 24 位。島民與導覽訪客只在所屬島的相連地塊之間散步、使用設施、接近房東聊天，不得跨島。路線層拒絕非房東的跨島請求，設施亦限制本島居民參加。
- 房東角色可以巡視中央戰情室及所有具名物件島。開啟「開始巡島」後點島／橋，或選目的地再按「走到這座島」。路線會沿島上步道和木橋行進；途中改目的地時，先走到下一個安全的島上接點再改道。
- 提供自動巡島、暫停／繼續及跟隨視角。手動選目的地會停止自動巡島；關閉自動後走完目前路線，按「暫停巡島」則立即暫停。房東位置與已巡視島數只存在本次頁面，重新整理會回中央戰情室，不寫入帳表。巡島不會自動標記收款或改動帳務。
- 頁面隱藏或切換至其他工作台時停止動畫；支援減少動態效果設定，停止水面與島民的背景動作，房東仍可接受使用者的移動指令。
- 城市在頁面可見、城市分頁開啟時每 60 秒讀取一次，也可手動同步；不是逐秒串流。切換至登錄或頁面隱藏時停止自動讀取與 3D 繪製。同步失敗時顯示錯誤並保留上次資料。
- 常住島民及互動資料只寫入 Apps Script 的私人 User Properties，與收款帳表分開。新增及互動以請求 ID 防止重送重複累加；住處物件不在所選月份時暫時顯示於中央戰情室。
- 3D 使用固定版本 Three.js 0.180.0 的 HTTPS 模組；不向圖形來源傳送帳表內容或帳號權杖。無法使用 WebGL 時保留文字清單、帳況及島民操作。

### 到島自動聊天
- 房東抵達指定島嶼後，會依序與該島所有常住島民及導覽訪客聊天；經過途中島嶼不會誤觸發。島民沿自己的環形步道走近房東，輪流顯示對話泡泡。
- 預設開啟「到島自動聊天」。自動巡島會等對話完成再走向下一島；沒有島民時直接續行。前往生活設施時會先聊天，再開始原本的活動。
- 可選「聊聊近況」「聊島上設施」，進入慢聊後以「下一句」接話，或恢復自動對話。「結束聊天」會回到原本行程，手動改目的地則中止對話並安全轉往新島。
- 對話採用內建的角色故事與島上設施資料，依角色、話題及本次拜訪次數變化，不使用外部 AI 或傳送帳表內容。每次登島最多保留最近 80 句對話，重新整理後清除，不寫入帳務、好感或拜訪紀錄。
- 巡島暫停、切換工作台或頁面隱藏時，對話進度也暫停；一般資料同步不會重新觸發聊天。

### 小島生活設施
- 中央戰情室配置 12 種生活設施：噴泉廣場、泳池、健身房、圖書室、球場、鋼琴室、咖啡座、野餐區、遊戲場、釣魚台、小菜園與小市集，另有 6 塊綠地休憩空間。物件島依地塊數配置 4 至 11 處設施，每處都有獨立地塊；5 塊地的小島保留泳池、健身房、圖書室與鋼琴室。
- 泳池有泳道、扶梯與躺椅；健身房有跑步機、啞鈴與瑜珈墊；圖書室有書架與閱讀桌；球場有球架與彈跳籃球；鋼琴室有琴蓋、黑白琴鍵與演奏音符動畫。鋼琴活動為視覺演出，不播放聲音。
- 點島後可從本島設施按鈕直接探索；總導覽依島名分組。各設施有獨立的活動次數與進度。
- 在「今天，想在島上做什麼？」選擇設施，也可從島嶼資訊進入。房東會沿步道、木橋抵達後體驗；島民只使用自己島上的設施，平時也會自行前往活動。
- 角色會從環島步道轉進設施入口，活動約 6 秒後回到步道；進出與聊天時間另外計算。島民會輪流使用本島不同設施。可以取消活動或暫停房東，繼續時保持原位置與進度。改目的地時，先沿入口回到步道再過橋。減少動態效果模式停用背景自動活動，仍接受手動指令。
- 生活活動只保留在本次頁面，不寫入 Google Sheets 或 User Properties，不改變收款、好感或拜訪次數。

## 收租戰情室
- 本月應收、實收、逐筆待收餘額、逾期未收、金額到位率。
- 最近 12 個日曆月份的應收／實收趨勢、上月比較及可展開的數值表；缺少月份分頁時顯示無資料。
- 逾期、含今天起 7 天內到期、金額或勾選狀態需核對的清單，可搜尋物件／類型並直接前往指定紀錄。
- 依物件彙整收款進度，顯示貸款欄合計及扣貸款後實收。
- 戰情室只有讀取操作。回到戰情室會重新彙整，切換前仍保護尚未儲存的輸入。

### 統計口徑
應收使用「本月應收」，僅在整欄不存在時才改用「應收金額」。空白或格式錯誤的應收不視為零；實收空白視為尚未收款。缺少金額時，合計只顯示已知部分並提示核對。

待收逐筆取 `max(應收－實收, 0)`，超收不抵扣其他物件的欠款。金額到位率按逐筆 `min(應收, 實收)` 計算，與「是否已收」勾選筆數分開。已勾選但不足額的紀錄仍會列為待收／逾期。

逾期依試算表時區的今天及每月應收日判斷，超出當月天數的應收日以月底計；未提供有效應收日時不推定逾期。歷史月份也依帳表目前狀態判斷，不代表當月底快照。月份收入按分頁歸屬彙整，不按實際入帳日重新分月。

貸款欄空白視為零；不存在或格式不明時不提供扣貸款後實收。該數字未扣稅費、修繕等其他支出，不能視為淨利。戰情室只讀取 Script Properties 指定的試算表，不接受前端傳入其他試算表 ID，也不共用私人資料快取。

## 部署
1. 在 Apps Script 放入 `apps-script/Code.gs`、`apps-script/Index.html` 和 `apps-script/City.html`。入口使用 HTML 範本載入城市元件。
2. 在 Script Properties 設定 `SPREADSHEET_ID`。驗收時指向私人測試副本，`APP_MODE` 保持 `TEST` 或空白。
3. 部署為網頁應用程式，執行身分「我」、存取權「只有我自己」。Google OAuth 由本人核准。
4. 在副本實測表單寫入、重新讀取及欄位保留，驗收後才把 `SPREADSHEET_ID` 切回正式試算表，並設定 `APP_MODE=LIVE`。
5. 入口只連到已驗證的 `/exec` URL。修改程式後需更新既有部署至新版本；Script Properties 不應加入 GitHub。

### 預先新增具名島嶼
在私人 Script Properties 設定 `CITY_EXTRA_ISLANDS`，內容為名稱的 JSON 陣列（例如 `["暮光公寓"]`）。城市會合併帳表物件名稱並去重；尚未有帳款的島顯示「尚無收款紀錄」，可入住、巡島與使用生活設施，不會建立帳表資料列或虛構金額。帳表出現同名物件後，自動呈現該月份帳況。島名與設定值不要提交至公開儲存庫。

### 近鄰短橋、專屬地塊與錯落布局
島嶼採緊湊的錯落配置，鄰近海岸以短橋直接連接，包含物件島之間的連線。每段橋都有長度上限，規劃時避開其他島嶼及橋梁；房東沿可通行路網巡視，不必每次返回中央。按「重新排列島嶼位置」可換一種配置並讓房東回中央。定時同步保留位置，重新整理頁面回到預設配置。舊的 `CITY_CENTRAL_ONLY_ISLAND` 設定不再限制路線。

在私人 Script Properties 設定 `CITY_ISLAND_PROFILES`，例如 `{"測試寓所":{"tiles":9},"舊顯示名稱":{"tiles":5,"displayName":"新顯示名稱"}}`。地塊數限 5 至 12；中央戰情室固定 19 塊，不受個別設定影響。顯示別名只改城市標籤，原帳表物件名稱、收款資料和島民住處識別保持不變。島名與設定值不要提交至公開儲存庫。未列出的物件預設 7 塊。

每塊六角地塊有環繞建築的步道，接壤地塊之間有連通走道。房東、島民進出外圍設施與回到聊天步道均使用同一套島內路網，避免直接穿過水面或建築。島民沒有跨島權限。

建築採 8 層大樓、露台公寓、透天、別墅與平房的微縮模型；陽台、樓層腰線、屋頂花園與夜間窗燈增加立體層次。模型為視覺設計，不代表實際建物資料。

### 中央島地標天際線
中央戰情室新增台北101、微風南山大樓與台北天空塔的微縮風格建築，分別使用竹節塔身、雙翼山形冠頂及圓潤直向立面。三棟集中於中央島內圈，與指揮中心相鄰；噴泉、泳池與鋼琴室移至原地標空間，保留中央島 19 塊地塊、12 處生活設施與環繞步道；點選模型或中央島的地標按鈕可拉近欣賞。窗燈沿用日夜光影，模型不代表實際樓高或樓層。

造型參考：[台北101](https://www.taipei-101.com.tw/en/concept/structure)、[微風南山設計](https://www.mjd.co.jp/en/projects/27998/)、[台北天空塔設計](https://acpvarchitects.com/project/the-sky-taipei-2/)。

### 房東巡島與中央休息
房東模型放大約 1.6 倍，點選房東或頭頂標籤可跟隨近看。「持續巡島」會循環拜訪各島並在聊天後繼續；「回中央休息」會沿現有步道與木橋返回中央，抵達後停下且不再自動出發。返回途中可以暫停、繼續或改選其他模式；在橋上改目的地會先抵達安全島內步道。仍可自選目的地，島民保持只在本島活動。

行程只在本次頁面保留；城市畫面隱藏時暫停，回到畫面後繼續，重新整理或重排島嶼後回到中央休息。上述操作不寫入收款資料。

### 自行布置建築
在城市右側工具列或登島資訊按「建築工坊」。可選 8 種建築（平房、別墅、透天、雙拼、公寓、大樓、合院、店住）、6 種外觀風格、1–12 層、6 種房型標示與四個朝向，並即時預覽 3D 模型。房型標示供城市造景，並非實際房屋格局。

每座物件島的主住宅可更換；中央戰情室另有三處庭園基地可新增建築。地標、指揮中心、十二處中央生活設施與步道保留。已配置建築可直接點選修改，或在工坊選基地再修改；「恢復原住宅／移除自建建築」會恢復原來住宅或庭園。

建築配置存在私人 User Properties，重新整理仍會保留，跨月份共用；不寫入帳表。儲存有版本衝突檢查與重試保護。套用配置後房東回中央休息；兩個頁面同時編輯時，較舊頁面須先關閉工坊、立即同步，再編輯。

### 所有角色都能改名
按城市工具列的「角色改名」或精靈區的同名按鈕，選擇房東、常住島民、九位散步訪客或三位隱藏彩蛋角色，再輸入 1–20 個字。也可在房東巡島區按「房東改名」，或選取島民後按「為角色改名」。每個角色可隨時恢復原名。

新名稱會顯示於角色卡、房東標籤、聊天與活動選單，並私人保存到 User Properties，跨月份與重新整理皆保留。改名依角色識別碼套用，不影響住處、好感或巡島進度。使用不同頁面同時改名時，較舊頁面須關閉改名視窗、立即同步後再改。

## 資料保護
- 收款登錄只修改「實際入帳日」「實收金額」「是否已收」「備註」四個輸入欄位；新增島嶼時勾選建立帳目，才會另加一筆未收款租金。
- 依唯一欄名定位，兼容各月份不同的欄位順序；缺少或重複欄名時停止寫入。
- 保留貸款、差額及其他公式。收款輸入欄若是公式或不可編輯，停止寫入。
- 驗證日期、非負金額、已收款必要欄位；備註以純文字寫入。
- 以資料版本檢查阻止覆寫已變動的紀錄，並鎖定應用程式的同時儲存操作。
- 載入月份時停用編輯；讀取失敗後不能用舊資料儲存。
- 若儲存失敗，請先重新讀取 Google Sheets 核對現況，再決定是否重新儲存。
- Google Sheets 原有分享權限獨立於 Web App 存取限制，部署不會修改原有分享設定。

## 驗證
執行 `node verify.cjs`，檢查兩種欄位排列、公式保留、錯誤輸入、資料版本衝突及備註純文字。另須在 Google 測試副本完成實際表單與試算表讀寫驗收。




### 私人島嶼資料
在物件島的「管理地址與文件」可保存地址、備註，以及 PDF／Word 保險與合約連結。先將原檔上傳至私人 Google Drive，再貼上文件連結；文件沿用 Drive 原本權限，請勿設為公開。地址及連結只保存於 Apps Script User Properties，不寫入帳表或公開網站。每島最多顯示 12 份文件，含最近移除最多 24 份紀錄，總資料限 8 KB；移除文件僅移除島上連結，可從「最近移除」還原，雲端原檔保留。保存具有版本檢查與重試保護。


### 海島生活與新增島嶼
新增島嶼支援 5–12 塊地塊，名稱與配置私人保存；可選擇同時建立所選月份的一筆租金帳目，填寫租金與應收日，實收金額及入帳日留空。採鎖定與建立識別避免重試重複新增。中央戰情室及各物件島皆可保存地址與文件。3D 人物為原尺寸兩倍，海面提供起伏波浪與五種避開島岸、橋梁的船。原創鋼琴／木琴旋律在首次互動後播放，可調音量或關閉，切到其他工作台或背景分頁會暫停。

房東在雙倍尺寸後再縮小約 16%，每輪巡島隨機排序並涵蓋各島。島嶼具有不同地面高度，橋面、步道、人物活動與跟隨視角同步配合。十艘船沿避開島岸、橋梁與其他船隻的水道自行航行；兩架小飛機與三顆熱氣球在天際活動。裝置設定減少動態效果時，船與飛行物保留靜態外觀。
